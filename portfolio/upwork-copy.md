## Project title

Spring Boot JWT Authentication and Role-Based Access Control

## Your role

Java Backend Developer

## Project description

Built a self-initiated Spring Security portfolio API with JWT authentication and role-based access control. The backend supports registration, login, protected profiles, USER/ADMIN permissions, rotating refresh tokens, logout revocation, BCrypt password hashing, and structured 401/403 errors. Raw refresh tokens are never stored; only SHA-256 hashes are persisted. I also added MySQL and H2 support, Swagger/OpenAPI bearer authentication, Docker Compose, GitHub Actions CI, and 9 automated integration tests.
